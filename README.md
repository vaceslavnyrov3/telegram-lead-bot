# Telegram-бот для приёма заявок

Бот собирает заявки клиентов и мгновенно присылает их владельцу бизнеса.

## Возможности
- Пошаговая анкета: имя → телефон (кнопкой или вручную) → услуга → комментарий
- Проверка введённых данных и подтверждение перед отправкой
- Отмена на любом шаге
- Уведомление владельцу о каждой новой заявке
- Хранение заявок в SQLite, команда `/leads` для владельца
- Список услуг и тексты легко меняются под любой бизнес

## Стек
Python 3.11+, aiogram 3, SQLite, python-dotenv

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
copy .env.example .env        # и впишите BOT_TOKEN и ADMIN_ID
python bot.py
```
